# Pre-registro — 25 de septiembre

Micrositio estático de pre-registro con generación de boleto para screenshot y envío de registros mediante Formspree.

Incluye precios ($80 con registro y $100 sin registro, ambos pagados en puerta), fecha, horario, lineup, ubicación enlazada a Google Maps y un formulario de nombre e Instagram. El boleto de $80 se muestra en la entrada. El sitio está contenido en `dist/` y la configuración incluida publica esa carpeta con GitHub Pages al actualizar la rama `main`.
