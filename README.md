# Pre-registro — 25 de septiembre

Micrositio estático de pre-registro con generación de boleto para screenshot y envío de registros mediante Formspree.

Incluye precios ($80 con registro y $100 en puerta sin registro), fecha, horario, lineup, ubicación y un formulario de nombre e Instagram. El sitio está contenido en `dist/` y la configuración incluida publica esa carpeta con GitHub Pages al actualizar la rama `main`.
